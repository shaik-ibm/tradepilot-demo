# TradePilot — live demo

**Open the demo:** https://shaik-ibm.github.io/tradepilot-demo/

TradePilot is an automated Binance **Spot** trading app (Smart LIFO Recovery & Profit Cycle).
This repository hosts only the **demo screens**: simulated prices and simulated money, running entirely
in your browser. It never connects to Binance and never places a real order.

* Sign in with the owner e-mail — the demo shows the one-time code on screen (no e-mail is sent).
* Use **Demo market** to move prices and watch purchases, newest-first sales and Reserve batches.

The real app runs on the owner's own computer or server, where API keys stay encrypted and never reach a browser.
